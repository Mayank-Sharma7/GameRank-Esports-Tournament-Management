# GameRank – Esports Tournament and Player Ranking Management System

## Project Overview

GameRank is a Database Management System (DBMS) mini project developed using MySQL. It is designed to manage esports players, teams, tournaments, registrations, and match results.

## Objectives

* To maintain player and team information.
* To store tournament details.
* To manage player registrations for tournaments.
* To record match results.
* To retrieve and rank player information using SQL queries.

## Technologies Used

* MySQL
* MySQL Workbench
* SQL
* GitHub

## Database Tables

1. Players
2. Teams
3. Tournaments
4. Registrations
5. MatchResults

## Project Files

* `GameRank_MySQL_Script.sql` – SQL commands used to create and populate the database and execute queries.
* `GameRank_Case_Study.pdf` – Project report and case study.
* `Screenshots/` – Screenshots showing SQL commands and their outputs.

## How to Run the Project

1. Install MySQL and open MySQL Workbench.
2. Open `GameRank_MySQL_Script.sql`.
3. Review the script before execution. If it contains `DROP DATABASE IF EXISTS GameRank;`, note that running it will delete an existing GameRank database and its data.
4. Execute the script in MySQL Workbench.
5. Run the SELECT queries to view the stored records and results.

## Conclusion

GameRank demonstrates how a relational database can be used to manage esports tournament information and player rankings through SQL.
